# ペットマッチングアプリ

## 概要
このアプリは、ユーザーとペットのマッチングを効率的に行うことを目的としたWebアプリです。
ユーザー側では、アンケートやクイズを通じて性格やライフスタイルを分析し、
	マッチング率やおすすめペットをもとに自分に合ったペットを探すことができます。
また、ペットの検索・詳細閲覧・予約・メッセージ機能を通じて、
	実際の見学ややり取りまで行うことができます。
施設側では、ペット情報の登録・編集・削除を行うことができ、
	施設が管理するペット情報をシステム上で適切に更新・管理することができます。
また、ユーザーからの予約やメッセージにも対応し、スムーズな運営を支援します。

これにより、ユーザーと施設の双方にとって使いやすく、
	ミスマッチの少ないペットマッチングサービスを目指しています。

## 主な機能
- ユーザー登録・ログイン・ログアウト
- アンケートによるユーザータイプ分析・ペット適性診断
- クイズ形式による飼育に関する基本知識の確認
- マッチング率の算出・表示
- ペット一覧表示・詳細表示
- 条件に基づいたペット検索
- 並び替え機能
- 検索条件による絞り込み機能
- おすすめペットの表示
- ペットの予約機能（見学）
- メッセージ機能（ユーザーと施設間のやり取り）
- マイページ機能（ユーザー情報の確認・編集）
- 施設ペットの登録・編集・削除機能
- お気に入り機能

## 技術スタック
- 言語: Java 25
- 画面: JSP
- サーバー処理: Servlet
- Webサーバー: Apache Tomcat（11.x）
- データベース: MySQL 8.0
- IDE: Eclipse

## 動作環境
- JDK 17 以上
- Apache Tomcat 11.x
- MySQL 8.0 以上

### 1. リポジトリのクローン
Eclipse の File > Import > Git からクローンするか、
コマンドラインで以下を実行します。
	
	git clone https://github.com/（自分のユーザー名）/yariika.git

### 2. データベースの準備
MySQL で以下を実行し、データベースとテーブルを作成します。
SQLファイルは `/db/schema.sql` に用意しています。

	 mysql -u root -p < db/schema.sql
	 
### 3. 設定ファイルの編集
`src/main/resources/db.properties` を開き、
自分の環境に合わせてDB接続情報を編集します。

    db.url=jdbc:mysql://localhost:3306/taskboard
    db.user=（自分のMySQLユーザー名）
    db.password=（自分のMySQLパスワード）
   
### 4. Eclipseへのインポートと起動
1. Eclipse でプロジェクトをインポート
2. プロジェクトを右クリック > Run As > Run on Server
3. Tomcat を選択して起動

### 5. アクセス
ブラウザで以下にアクセスします。

    http://localhost:8080/yariika/WelcomeServlet

## 使い方
### ユーザー側
1. 初回はトップの「新規登録」からアカウントを作成
2. 作成したアカウントでログイン
3. アンケートに回答し、ユーザー分析を行う
4. おすすめペットやマッチング結果を確認する
5. ペット一覧から気になるペットを検索・閲覧する
6. 気になるペットに対してクイズを受け、飼育適性を確認する
7. クイズ結果を踏まえて必要に応じて予約を行う
8. メッセージ機能でユーザーとやり取りを行う

### 施設側
1. 施設アカウントでログインする
2. マイページから施設情報を確認・編集する
3. ペット情報の登録・編集・削除を行う
4. 登録したペット情報を一覧で管理する
5. ユーザーからの予約内容を確認し対応する
6. メッセージ機能でユーザーとやり取りを行う
